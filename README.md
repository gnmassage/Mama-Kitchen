# Mama-Kitchen
# 👩‍🍳 Mama Kitchen Tbilisi — Ukrainian Home Food Delivery

A high-performance, single-page web application built for **Mama Kitchen Tbilisi** (`mama_kitchen_tbilisi`), focusing on authentic Ukrainian home-cooked meals delivery in Tbilisi, Georgia.

---

## ✨ Features

- **❤️ Deep Emotional Branding**: Nostalgic storytelling & warm home-cooked messaging.
- **🌐 4-Language Dynamic Switcher**: Instant client-side switching between **Georgian (KA)**, **English (EN)**, **Ukrainian (UK)**, and **Russian (RU)**.
- **🛒 Smart Telegram Integration**: Dynamic cart calculation with automated localized order syntax sending straight to Telegram.
- **🥗 Dietary Filters**: Quick categorization for Meat, Vegetarian, and Sweet options.
- **🎁 Promotional Incentive**: Integrated first-order gift banner automatically included in Telegram order syntax.
- **⚡ Zero-Dependency Performance**: Pure HTML5, CSS3, and ES6 Vanilla JavaScript optimized for Vercel.
- **🔍 Full Local SEO & Schema.org**: Rich structured data (`Restaurant` / `FoodDelivery`), OpenGraph cards, and local Tbilisi keywords.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (CSS Variables, Responsive Grid), JavaScript (Vanilla ES6+)
- **Typography**: Google Fonts (*Plus Jakarta Sans*)
- **SEO**: Schema.org JSON-LD Structured Data & OpenGraph Protocol
- **Deployment**: Vercel
